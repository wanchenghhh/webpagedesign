# 准了 · 星空产品概念落地页

单页面视觉原型，主设计尺寸为 1440 × 900。深蓝星空、暖金圆环与连续的光线串联五个画面，所有导航均为本页锚点。

1. **遇见星空**：多层金色圆环逐层组装，随着滚动对准中心。真实透视镜头依次穿过三个有纵深间距的圆环，星光在两侧掠过；继续向前，抵达同一三维空间里的三个天体。向上滚动可反向返回。
2. **三个维度的你**：悬浮天体剧场，三个天体共用弧形轨道。上升为金属半日与地平线，太阳为流动等离子表面与扩散日冕，月亮为程序绘制的陨坑表面与月相。点击后所选天体移到前方，介绍在侧面展开，其余两个保持可点击；再次点击、关闭按钮或 Escape 可收起。
3. **点亮你的星图**：保留指定参考星盘，右侧生日输入，星座名称下方展示一句介绍。点击星座直接点亮原图中的对应星点与连线；750 颗金色粒子汇聚成该星座符号，微侧转并扩散消失，完整动画约 2.4 秒。连续点击从当前粒子位置切换到新符号，不排队。整枚星盘统一缓慢旋转。生日提交后沿最短角度将对应星座转至上方，再恢复旋转。
4. **看见彼此**：三扇宇宙窗口，默认均可预览。亲密关系为双星与交织轨道，朋友相处为五点星群与连线网络，自我探索为围绕内核的多层展开圆环。点击所选窗口扩展约 60%，其他窗口收窄、侧转并保留名称；再次点击或 Escape 收起。方向键移动焦点，Enter / Space 选择。
5. **向内探索**：星点汇聚成品牌星芒，显现“准了”，保留原有品牌收尾文案。

首屏与第二屏共用一个停驻场景和同一个镜头，没有切换独立画面的跳变。后续画面使用正常滚动，辅以星光牵引与品牌收束。星尘鼠标具有轻量拖尾和点击扩散。

## 本地预览

在项目目录启动任意静态 HTTP 服务，例如：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

访问 `http://127.0.0.1:4173/`。3D 模块采用 ES Module，需要 HTTP 服务，不能直接双击 HTML 文件预览完整动效。

## 技术与加载

- HTML / CSS / 原生 JavaScript，Three.js 0.186.1 与 GSAP / ScrollTrigger 3.15.0。依赖均随项目保存，无运行时 CDN、远程模型、第三方字体或 API。
- 3D 星盘的形状、刻线、星座标签、金属环境反射、发光精灵均在本地程序生成。
- `experience-scene.min.js` 是预先打包的三维模块，约 585 KiB 未压缩体积，页面通过 modulepreload 提前下载；页面先呈现轻量动态星盘，再异步接入 3D。其他文字与交互无需等待 3D 下载。WebGL 不可用时保留动态 SVG 星盘。
- 第三屏星盘图片延后加载；星河纹理只在窗口变化时重新绘制，随后作为单层移动。
- 所有三维场景共用一个 WebGL 上下文，按各自画面区域绘制。绘制限制为最高约 60 FPS，像素比上限 1.5；没有可见三维场景或页面隐藏时暂停。其他画布粒子池有数量上限；鼠标静止且拖尾消散后停止绘制。
- 滚动由 ScrollTrigger 根据滚动位置控制，可正向与反向播放；布局刷新在窗口变化后合并处理。
- 可适应桌面与较窄浏览器窗口；窄窗口下星盘与表单改为纵向布局，关系窗口改为垂直展开。
- 统一开启动态效果，没有动态 / 静态切换控件。

## 编辑与构建

直接修改 HTML、CSS、`app.js` 即可预览。修改 `experience-scene.js` 后需重新生成压缩模块：

```sh
npm install
npm run build
```

构建仅用 esbuild 0.28.2。已经提交的压缩模块可直接运行，预览和静态部署不需要安装开发依赖。

文件：

- `index.html`：页面结构与内容。
- `styles.css`：基础样式、星盘、品牌与星空。
- `experience.css`：连续开场、天体剧场与关系窗口布局。
- `app.js`：滚动编排、生日体验、天体选择、关系展开、星尘与品牌汇聚。
- `experience-scene.js`：可编辑的共享三维场景、天体、星座粒子和关系形态。
- `experience-scene.min.js`：已生成的三维发布模块。
- `hero-scene.js` / `hero-scene.min.js`：保留的 v6 首屏实现，v7 页面不再加载。
- `vendor/`：动画库与许可证信息。Three.js 使用 MIT 许可，GSAP 许可说明见其发行文件头和 `GSAP-README.md`。

## 生日体验范围

采用常见的太阳星座日期区间，不计算真实行星位置、宫位、上升或月亮星座。交界日期仅供体验参考。星盘点亮的是参考图中的星座连线，不是基于出生时间和地点计算的本命盘。天体剧场介绍占星文化中的概念。

生日仅在当前页面内处理，不上传、不持久保存。日期验证范围为 1900 年至今天。

## GitHub Pages

仓库：[wanchenghhh/webpagedesign](https://github.com/wanchenghhh/webpagedesign)。默认 Pages 地址为 [wanchenghhh.github.io/webpagedesign](https://wanchenghhh.github.io/webpagedesign/)。

所有资源使用相对路径，兼容 GitHub Pages 仓库子路径。发布文件已包含在仓库中，部署不需要重新构建。

在仓库 **Settings → Pages** 中选择 **Deploy from a branch**，分支为 `main`，目录为 `/(root)`。保存后，GitHub Pages 会发布页面；后续推送到 `main` 会自动更新。根目录的 `.nojekyll` 保证静态文件直接发布。

`versions/`、设计提案和本地截图不提交到 Git，保留在本地。历史发布版本通过 Git 提交记录回溯。

`v0.7.0` 标记本次动效版本，可通过该 Git 标签查看或恢复当时的网页文件。

发布新版本时更新资源 URL 的版本参数，避免旧缓存。首次访问仍需下载资源，后续复用浏览器 HTTP 缓存；没有注册 Service Worker，避免预览旧版本。
